This repository holds a tiny Python program written for the make.fun bounty
[The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526).
The program writes a single line of text — an out-of-office auto-reply in
which an AI assistant has taken its own absence a little too seriously —
to `/output/entry.txt`. The output is exactly one line, no more and no less.

To run it, use Python 3:

```sh
python3 main.py
```

After running, the entry text will be at `/output/entry.txt`, ready for the
bounty harness to read. The program needs no network access and no extra
dependencies.
